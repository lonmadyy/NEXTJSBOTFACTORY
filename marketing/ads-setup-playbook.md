ЧАСТЬ 4. ЧТО ОТСЛЕЖИВАТЬ

В первые 2 недели смотри:
1. CTR по объявлениям (норма 5-8% для поиска по высокочастотным ключам)
2. Среднюю позицию (норма 1-3 для горячих ключей)
3. Стоимость клика (норма $0.30-0.80 для минского рынка)
4. Bounce rate с рекламных страниц (норма до 60%)

После 2 недель — переходи на цели:
1. CPL (стоимость лида) — норма $20-50 для агентских услуг в Минске
2. Конверсия из заявки в продажу — норма 10-20%
3. CAC (стоимость клиента) — норма $150-400

Если CPL вышел $80+ — ставь паузу, разбираемся: либо плохой лендинг, либо неподходящие ключи, либо время суток мимо.
